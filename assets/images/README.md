# App Icons and Wallpaper

This folder contains the iPhone simulator images.

## Wallpaper
- **wallpaper.png** - Replace with your custom iPhone wallpaper
  - Recommended size: 390x844px (iPhone 14/15 Pro) or 1170x2532px (3x resolution)
  - Format: PNG
  - Will be displayed as the home screen background

## App Icons
Upload SVG files with these exact names to replace the default gradient backgrounds:
- **facetime.svg** - FaceTime app icon
- **messages.svg** - Messages app icon
- **phone.svg** - Phone app icon
- **facebook.svg** - Facebook app icon
- **twitter.svg** - Twitter/X app icon
- **whatsapp.svg** - WhatsApp app icon

**Note**: If icon files don't exist, the plugin will use gradient backgrounds as fallbacks. All icons should be SVG format with rounded corners already applied (iOS standard: 13px border-radius at 60px size).
